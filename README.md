# YouTube 观看记录 · 一键移除按钮

在 YouTube 观看记录页（`https://www.youtube.com/feed/history`）为每条记录显示一个删除按钮，
点一次即可完成「更多操作 → 从观看记录中移除」两步操作，不必展开二级菜单。

- 适用页面：桌面版 YouTube 观看记录页
- 运行环境：Tampermonkey 或同类用户脚本管理器
- 许可：MIT

## 安装

1. 安装 Tampermonkey。
2. 打开 Tampermonkey 面板，选择「添加新脚本」，清空模板内容。
3. 粘贴 `yt-history-remove.user.js` 全文并保存。
4. 打开 `https://www.youtube.com/feed/history`。

页面加载后，每条记录右下角出现圆形删除按钮，鼠标移上去变红。

## 使用

- 点击按钮：脚本打开该条目的「更多操作」菜单，并选中「从观看记录中移除」。
  请求组装、埋点、提示条、列表更新、撤销入口均由 YouTube 处理，与手动操作两次一致。
- 删除失败时按钮恢复可用，再点一次即可重试。
- 脚本不自行调用 YouTube 接口，因此不存在参数缺失导致的 400。

## 实现要点

### 走 YouTube 自己的菜单项

脚本以程序方式触发官方交互：点击条目上的「更多操作」，再点击「从观看记录中移除」。

### 按数据模型识别元素

YouTube 的 `yt-*-view-model` 元素把渲染数据挂在 `data` 属性上，脚本据此判定：

| 目标     | 判定方式                                                    |
| -------- | ----------------------------------------------------------- |
| 菜单按钮 | `data.onTap.innertubeCommand.showSheetCommand` 存在的那一个 |
| 删除行   | `data` 中的 `feedbackToken` 属于当前视频的那一行            |

界面语言变化、YouTube 复用菜单节点、页面残留其它面板，都不会造成误点：
带模型但不属于当前视频的行一律跳过。取不到 `data` 的旧 DOM 退回「可见 + 文案匹配」。

### 数据来源

`feedbackToken` 与文案取自 `window.ytInitialData` 与 `/youtubei/v1/browse` 的响应，无需额外请求。

## 配置项

脚本顶部有两个开关：

| 名称         | 默认值  | 说明                                           |
| ------------ | ------- | ---------------------------------------------- |
| `DEBUG`      | `false` | 改为 `true` 后始终打印详细日志                 |
| `HOVER_ONLY` | `false` | 改为 `true` 后按钮仅在鼠标移到该条记录上时显示 |

## 日志与调试

默认打印关键路径日志，每行带时间：

| 日志                                                                        | 含义                             |
| --------------------------------------------------------------------------- | -------------------------------- |
| `脚本已运行（v…）：/feed/history`                                           | 脚本已启动，并说明详细日志状态   |
| `扫描：卡片 N，已加按钮 M，无法识别视频 X，缺 token Y，token 覆盖 Z 个视频` | 页面识别情况，数字变化时打印一次 |
| `点击删除 <videoId>（token N 个）`                                          | 每次点击的起点                   |
| `已删除 <videoId>：用时 Xms`                                                | 删除成功                         |
| `删除失败 <videoId>：<原因>`                                                | 未点中菜单项，按钮已恢复可用     |
| `按钮被 <元素> 遮住，已提高层级`                                            | 置顶自检发现遮挡，已自动提升层级 |

详细日志默认关闭，两种打开方式：

```js
__ytdb.debug(true); // 临时打开，立即生效
localStorage.ytdb = "debug"; // 持久打开，刷新后仍有效；清除用 localStorage.removeItem("ytdb")
```

状态快照：`__ytdb.dump()` 返回版本号、token 覆盖的视频数与文案缓存。

## 界面细节

按钮固定在条目右下角：观看记录是「左封面 + 右信息」的两栏结构，压在封面上不易看清。
视觉尺寸 30px，可点击区域 40×40；键盘焦点环为白环加黑描边，因为 YouTube 的样式表中有大量
`outline: none` 复位；按下时轻微缩放，并遵循系统的减少动效设置。

## 已知限制

- 删除前没有二次确认，与手动操作一致；YouTube 会给出带撤销的提示条。
- 脚本以程序方式触发菜单，屏幕上可能出现极短的面板闪动。
- 同一视频在记录中存在多条时，每次点击只删一条。

## 排查

1. 确认当前页面是 `https://www.youtube.com/feed/history`。
2. 控制台应有两行：`脚本已运行（v…）…` 与 `扫描：…`。两行都没有说明脚本未运行。
3. 「已加按钮」长期为 0 时，执行 `__ytdb.dump()` 并附上结果。
4. 点击后出现 `删除失败` 时，打开 `__ytdb.debug(true)` 复现一次，附上日志。
